# Request to university IT: Student Connect email sender

Student Connect needs to send account-verification and password-reset emails to students at `ppsu.ac.in`. The application uses Supabase Authentication. Please approve one of these options:

## Option A: University SMTP relay

Provide a dedicated sender such as `studentconnect@ppsu.ac.in` with permission to send transactional messages through an SMTP relay. We need:

- Approved From address and display name.
- SMTP hostname, port and TLS requirements.
- Dedicated SMTP username and password/app credential, shared through an approved secure channel.
- Sending limits and any IP allowlist requirements; the sender runs in hosted Supabase, not on a fixed personal PC.
- Confirmation that this relay supports the authentication method Supabase SMTP accepts. A browser-only mailbox login is not sufficient.

Do not provide an administrator account, a staff member's personal password or unrestricted access to the university mailbox system. Credentials will be stored only in Supabase's server-side email settings.

## Option B: Dedicated subdomain with Resend

Approve a sending subdomain such as `connect.ppsu.ac.in` and a From address such as `noreply@connect.ppsu.ac.in`. University IT retains DNS control and adds the exact DKIM and SPF/return-path records generated by Resend for that subdomain. Confirm the university permits Resend to process these transactional messages, and identify the account owner and IT contact.

We will supply exact DNS names and values after the subdomain is approved. Do not replace the university's root MX records, existing SPF policy or staff/student email routing. Any DMARC changes should be reviewed by university IT.

## Validation

After sender setup, arrange one consenting student test account to check verification and password reset, then another authorized account to test campus interactions. The login domain stays `ppsu.ac.in`; email verification will not be bypassed. First-administrator identity must be approved separately.

References: [Supabase SMTP](https://supabase.com/docs/guides/auth/auth-smtp), [Resend domain verification](https://resend.com/docs/dashboard/domains/introduction).
